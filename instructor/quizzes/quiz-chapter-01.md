# Chapter 1 Quiz: Introduction & Philosophy

## Quiz Questions

### Multiple Choice

**1. Who created the Linux kernel in 1991?**
- A) Richard Stallman
- B) Linus Torvalds
- C) Bill Gates
- D) Steve Jobs

**Answer:** B

**2. What does GNU stand for?**
- A) Generally New Unix
- B) GNU's Not Unix
- C) Global Network Utility
- D) Graphical Network User

**Answer:** B

**3. Which of the following is NOT a characteristic of open-source software?**
- A) Source code is available to everyone
- B) Anyone can study and modify the code
- C) You must pay to use the software
- D) Anyone can distribute the software

**Answer:** C

**4. Linux powers:**
- A) All Android devices
- B) Most web servers
- C) Most supercomputers
- D) All of the above

**Answer:** D

**5. What is a Linux distribution?**
- A) A company that sells Linux
- B) A complete operating system built around the Linux kernel
- C) A programming language for Linux
- D) A type of Linux kernel

**Answer:** B

### True/False

**6. True or False: Linux is just a kernel, not a complete operating system.**

**Answer:** True

**7. True or False: You must pay money to use Linux.**

**Answer:** False

**8. True or False: The Linux kernel is proprietary software owned by a single company.**

**Answer:** False

**9. True or False: Linux follows the Unix philosophy of small programs that do one thing well.**

**Answer:** True

**10. True or False: Only programmers can use Linux effectively.**

**Answer:** False

### Short Answer

**11. What are the four essential freedoms defined by the Free Software movement?**

**Answer:**
1. Freedom to run the program for any purpose
2. Freedom to study how the program works and change it
3. Freedom to redistribute copies
4. Freedom to distribute copies of modified versions

**12. Why is Linux popular for servers and supercomputers?**

**Answer:**
- Free and open-source (no licensing costs)
- Highly stable and reliable
- Secure by design
- Customizable and flexible
- Strong community support
- Can run without a GUI (saves resources)

**13. What is the difference between the Linux kernel and a Linux distribution?**

**Answer:**
The Linux kernel is the core of the operating system that manages hardware and provides services. A Linux distribution is a complete operating system that includes the Linux kernel plus package managers, desktop environments, utilities, installation tools, and other software that make it usable.

### Discussion Question

**14. Why might someone choose Linux over Windows or macOS? Discuss at least three reasons.**

**Sample Answer:**
- Privacy: Linux doesn't collect user data like major corporations
- Freedom: Complete control over your system
- Cost: Free to install and use
- Security: Less vulnerable to malware
- Customization: Change anything about how it looks and works
- Development: Better programming environment
- Learning: Understand how computers work
- Ethics: Support free and open-source software

## Instructor Notes

### Common Misconceptions to Address

1. **"Linux is hard to use"** - Modern distributions are user-friendly
2. **"Linux is only for programmers"** - Many non-technical users use Linux daily
3. **"Linux is all command-line"** - Modern Linux has excellent GUIs
4. **"There's no software for Linux"** - Thousands of applications available

### Teaching Tips

- Show real-world examples: Android phones, web servers, smart devices
- Demonstrate a live Linux system to show it's not scary
- Emphasize the community aspect - people help each other
- Connect to students' interests (gaming, privacy, development)

### Extension Activities

- Have students research a Linux distribution and present to class
- Explore GNU project website
- Look at source code of a simple open-source project
- Interview someone who uses Linux professionally

# Research Plan: Linux Course

## Proposed Research Areas

### 1. Linux Curriculum Structure Research
**Goal:** Identify optimal topic progression from beginner to intermediate
- Search for university-level Linux course syllabi
- Find proven learning sequences for CLI mastery
- Research common pain points for Linux beginners
- Identify "wow factor" topics that engage students

### 2. Fedora & Debian Specifics
**Goal:** Ensure distribution-accurate content
- Package management differences (dnf vs apt)
- Fedora vs Debian default configurations
- GNOME-specific workflows in both distros
- Installation procedures for both

### 3. mdBook Best Practices
**Goal:** Create effective technical documentation
- mdBook structure conventions
- Syntax highlighting options for shell/output
- Diagram and visual embedding strategies
- Educational content patterns for mdBook

### 4. Git & Docker Introductory Curriculum
**Goal:** Define scope for introductory coverage
- Essential Git commands for beginners
- Docker basics level appropriate for Linux newcomers
- Integration with Linux CLI workflows

### 5. Capstone Project Examples
**Goal:** Design meaningful final project
- Common Linux sysadmin tasks for beginners
- Complete setup checklist for daily driver use
- Project complexity appropriate for 15-hour course

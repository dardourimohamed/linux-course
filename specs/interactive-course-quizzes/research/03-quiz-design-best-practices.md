# Research: Quiz Design Best Practices

## Key Principles

### 1. Clarity & Accessibility
- Use **plain language** - avoid jargon
- Ensure all learners can comprehend queries easily
- Write clear, unambiguous questions

### 2. Learning Experience Focus
- Quizzes should be a **learning experience**, not just assessment
- Allow students to use resources
- Focus on key concepts rather than trivia

### 3. Question Design
- **Write fewer, more difficult questions** (quality over quantity)
- Include plausible distractors for multiple choice
- Align questions with learning objectives

### 4. Progressive Difficulty
- Build from concepts to implementation
- Scaffold learning experiences

## Technical/Coding-Specific Best Practices

### Question Types
- **Code completion** - Fill in missing parts
- **Debugging exercises** - Find and fix errors
- **Multi-step challenges** - Build complex solutions
- **Conceptual checks** - Test understanding before coding

### Practical Application
- Include hands-on coding exercises
- Use real-world scenarios
- Make exercises relevant to actual work
